# Mac Conversion Reference

Start with the [UI/UX Guide and Parity Checklist](mac-ui-parity.md), then review the [37-Screenshot Gallery](mac-ui-gallery.md).

- [Browser Gallery](mac-ui-gallery.html): open locally after cloning for a scrollable visual reference.
- [Screenshots and Capture Manifest](images): original PNG captures and build identification.
- [Complete Reference ZIP](mac-port-reference-2026-11-04.zip): the original November 4 handoff, including a Windows UI source snapshot. Its internal folder layout is preserved; open START-HERE.txt after extracting.
- [Captured Design Guidelines](design-reference.md): the exact color, typography, control, and layout reference used for these captures.
- [Current Design Guidelines](../docs/design.md): ongoing project design requirements.

The captures include local Windows UI changes newer than base commit `fc37458`. The ZIP preserves that source reference even if another checkout has not received those application changes yet. It is reference material, not a buildable Mac project.

Use this folder as the shared reference between Windows and Mac. Discuss differences in chat and record accepted decisions in the guide. No account databases or credentials are included.
