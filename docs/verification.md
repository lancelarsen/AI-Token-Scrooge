## GitHub sign-in focus crash investigation

Windows Application event 1000 recorded the configured preview crashing at 19:50:59 CDT on October 25, 2026, in `Microsoft.UI.Xaml.dll` with exception code `0xc000027b`. Radar's sanitized stack showed `COMException` from `IFocusManagerGotFocusEventArgsMethods.get_NewFocusedElement`, called by MAUI `ViewHandler.FocusManager_GotFocus`. The original log omitted the HRESULT, so it does not establish the precise underlying COM failure or a fix.

The diagnostic build adds timestamp and HRESULT without exception messages or provider data; diagnostic-write failures cannot replace the original exception. It reopened successfully, and the user's Sign in with GitHub action reached GitHub's device authorization page. At that diagnostic stage, authorization and billing success were still unverified; the later allowance build passed one personal account, as recorded below.

Source inspection also found background refresh rebuilding the covered dashboard controls. Rendering is now deferred while the dashboard is hidden by a modal, then requested on return; collection and tray updates continue. Release compilation passed with zero warnings/errors. This change was not in that historical diagnostic build; it is included in the current allowance build. Native Settings entry and return passed; sustained covered-page refresh verification remains open. It is not established as a fix for the observed crash.

### October 25 GitHub sign-in correction

The subsequent diagnostic crash at 20:05:14 CDT identified `COMException` HRESULT `0x80004005` from `IFocusManagerLostFocusEventArgsMethods.get_OldFocusedElement` in MAUI `ViewHandler.FocusManager_LostFocus`. A Windows-only workaround now handles only this HRESULT with either the exact GotFocus/NewFocusedElement or LostFocus/OldFocusedElement getter/callback pair. Other exceptions retain the ordinary fatal behavior. Recovered events use a separate bounded last-focus-recovery log without exception messages, codes, or credentials. The framework source inspected was MAUI 10.0.120 `src/Core/src/Handlers/View/ViewHandler.Windows.cs`.
