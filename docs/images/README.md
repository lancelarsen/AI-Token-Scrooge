# README Screenshots

These images were captured from the native Windows development preview in `--demo` mode on October 31, 2026. Account names, usage values, and events are synthetic. No authenticated account data or credentials are included.

- `dashboard.png`: Reset Horizon, history, event navigation, and an account quota section.
- `accounts.png`: Multiple providers and multiple quota windows per account.
- `settings.png`: Global notification, time-zone, and sound settings.

The screenshots represent the working development preview and may be ahead of a published package. They are actual app captures, not design mockups.

The synthetic history uses idle periods and uneven bursts inspired by aggregate usage patterns. No actual account readings were copied. The account screenshot includes green normal, blue info, yellow warning, and red critical usage bars.
